# Public repository boundary

This repository publishes implementation, methodology, aggregate evaluation
results and synthetic examples. Operational frames, videos, model weights,
internal presentations, meetings, assistant context and academic deliverables
are local artifacts, not public demo dependencies.

Removing tracked files does not erase previous commits. Historical commits
contain internal documents and imagery; the current cleanup must not be
interpreted as history sanitization. A separate coordinated history rewrite
and review of remote refs, forks and cached copies is still required if those
materials must be withdrawn completely. No history rewrite is performed by
this change.

Local documents remain at their existing paths so reporting workflows continue
to work. New public figures must be derived from aggregate metrics or synthetic
data, or have explicit distribution permission.

No public download for the operational datasets or trained weights is offered.
Access is subject to the applicable owners' authorization. Availability of
source code does not grant redistribution rights to third-party artifacts.

The repository currently has no project-wide open-source license. Establish
ownership and select an appropriate license before representing it as freely
redistributable. Third-party libraries and model artifacts retain their own terms.
