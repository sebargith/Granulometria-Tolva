COMO CORRER INFERENCIA YOLO PARA DETECTAR MATERIAL EN TOLVA
===========================================================

1. Abrir PowerShell y entrar al proyecto

cd "D:\Memoria\Granulometria"


2. Activar el entorno

conda activate memoria-dexined


3. Verificar el modelo

models\haul_truck_segment_m_736_low_data_aug_07012025.pt

Metadata:
task = segment
imgsz = 736
class 0 = caex
class 1 = material


4. Preparar imagenes de entrada

Poner frames originales del camion en una carpeta como:

input\Data test 1
input\Data test 2

Formatos soportados: JPG, JPEG, PNG, BMP, TIFF y WEBP.


5. Ejecutar inferencia filtrando solo material

python predict_tolva.py `
  --source "input\Data test 2" `
  --conf 0.25


6. Revisar resultados

Para el input "Data test 2", la salida se crea en:

outputs\yolo_carga\data_test_2

Contenido:

masks\          mascaras binarias de material
overlays\       imagen original con mascara superpuesta
predictions.csv resumen de detecciones por imagen
params.json     parametros de la corrida

Si la carpeta ya existe, el script agrega fecha y hora para no sobrescribirla.


7. Ajustes utiles

Si detecta poco:
--conf 0.15

Si detecta ruido:
--conf 0.40

Para procesar solo algunas imagenes:
--max-images 20

Para incluir la vista nativa de Ultralytics:
--save-model-preview


============================================================
GENERAR PATCHES PARA CLASIFICACION GRANULOMETRICA
============================================================

Opcion recomendada, desde frames originales:

python "modelos percepcion\carga_tolva_yolo\preparar_patches.py" `
  --source "Data parches test" `
  --run-name data_parches_test_carga `
  --open-labeler

Este comando:
1. Segmenta material con haul_truck...pt.
2. Guarda mascaras en outputs\yolo_carga.
3. Genera patches 128x128 con stride 128 y cobertura minima 80%.
4. Abre Streamlit usando los patches generados.

Si las mascaras ya existen, ejecutar manualmente:

python tools\patch_labeler\generate_patches.py `
  --source "Data parches test" `
  --mask-dir "outputs\yolo_carga\experimento\masks" `
  --run-name prueba_patches `
  --patch-size 128 `
  --stride 128 `
  --min-valid-fraction 0.8

Si los recortes tienen fondo negro, agregar al comando:
  --mask-black-background --foreground-threshold 8

Salida:
outputs\patches\prueba_patches\patches.csv


============================================================
ETIQUETAR PATCHES
============================================================

Para el experimento generado en esta prueba:

python tools\patch_labeler\launcher.py `
  "outputs\patches\data_parches_test_pipeline"

Tambien se puede hacer doble clic en "Etiquetar parches.lnk". El acceso
directo abre automaticamente el dataset generado mas reciente.

Desde PowerShell, para seleccionar otro dataset:

python tools\patch_labeler\launcher.py `
  "outputs\patches\prueba_patches"

Ejecucion directa con Streamlit:

streamlit run tools\patch_labeler\app.py -- `
  --dataset "Data parches test"

La interfaz se abre en http://localhost:8501 y guarda cada decision en
labels.csv dentro de la carpeta seleccionada.
